# Stellarity 末地

![](https://prismaticshards.wiki.gg/images/Stellarity-Logo.png)

[Stellarity 的 Modrinth 页面](https://modrinth.com/datapack/stellarity)

本页面所有内容由 1Dot 格式化自 [Stellarity - Prismatic Shards Wiki](https://prismaticshards.wiki.gg/wiki/Stellarity)，将所有条目展平并提供了与资源包一致的简体中文本地化对照，希望能提供更方便的阅读和搜索体验。

Stellarity 是一个数据包，它对末地进行了大幅改造，赋予它全新的地形形状、生物群系、物品和武器，甚至全新的机制。Stellarity 并没有遵循《我的世界：地下城》风格扩展的常见主题或将其变成纯外星维度，而是将荒凉维度的经典基调与强烈的魔法和奇幻主题完美融合在一起。

> [!NOTE] 自己探索
> 有许多作者没有设立页面的 Stellarity 物品，这里也无法索引，请自己摸索发现
>
> 时刻关注你按 `L` 键打开的进度屏幕中的「诅咒祭坛」和「末地」条目，其中诅咒祭坛 Tab 中记录了所有你能够在末地的诅咒祭坛尝试的合成表

## 附魔

### <img alt="暴击之刃" src="https://prismaticshards.wiki.gg/images/Invicon_Netherite_Sword.png" width="32" style="image-rendering: pixelated; display: inline-block; vertical-align: middle;"> 暴击之刃 Critical Strike

| 属性 | 值 |
| :--- | :--- |
| **推荐物品** | 剑 |
| **适用物品** | 剑，斧 |
| **来源** | 末地城的宝库战利品 |
| **不兼容** | 锋利，亡灵杀手，节肢杀手 |
| **最高等级** | 3 |

使攻击有 `附魔等级 * 10%` 的几率造成双倍伤害。

### <img alt="漂浮之箭" src="https://prismaticshards.wiki.gg/images/Invicon_Arrow_of_Slow_Falling.png" width="32" style="image-rendering: pixelated; display: inline-block; vertical-align: middle;"> 漂浮之箭 Levitation Shot

| 属性 | 值 |
| :--- | :--- |
| **适用物品** | 弓 |
| **来源** | 村民出售，权重 2 |
| **最高等级** | 5 |

使弓有 `[15 + 10 * (附魔等级 - 1)] / [100 + 12 * (附魔等级 - 1)] * 100%` 的几率将箭矢变为悬浮之箭，对命中的目标施加漂浮效果。

效果的持续时间是随机的，并随等级提升：
- 最短时间为 4 秒。
- 最长时间为 7 秒。
- 每一级都会使最短和最长持续时间增加 0.5 秒。

### <img alt="装甲" src="https://prismaticshards.wiki.gg/images/Invicon_Elytra.png" width="32" style="image-rendering: pixelated; display: inline-block; vertical-align: middle;"> 装甲 Plated

| 属性 | 值 |
| :--- | :--- |
| **适用物品** | 鞘翅 |
| **来源** | 村民出售，权重 2 |
| **不兼容** | 翱翔 (Soaring) |
| **最高等级** | 4 |

增强鞘翅，使其提供 `1 + 附魔等级` 点护甲。

从等级 3 及以上开始，它还会提供 1 点盔甲韧性（不受等级影响）。

每一级都会使飞行距离略微减少 `(1 + 附魔等级 * 3)%`。

### <img alt="翱翔" src="https://prismaticshards.wiki.gg/images/Invicon_Elytra.png" width="32" style="image-rendering: pixelated; display: inline-block; vertical-align: middle;"> 翱翔 Soaring
